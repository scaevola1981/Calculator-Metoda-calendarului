# AuraCycle — Calendar Menstrual & Metoda Calendarului

Aplicație web completă într-o singură pagină (Single Page Application - SPA), găzduită direct pe GitHub Pages, creată cu design mobil iOS Glassmorphism inspirat din ecranul de calendar Stitch.

🔗 **Demo Live GitHub Pages:** [https://scaevola1981.github.io/Calculator-Metoda-calendarului/](https://scaevola1981.github.io/Calculator-Metoda-calendarului/)

---

### 🎨 Sistemul Cromatic Oficial (Coduri HEX):
1. **Faza Menstruală (Zilele 1 – 5):** `#EE9DCB` (Roz trandafiriu, 5 zile)
2. **Faza Foliculară (Zilele 6 – 10):** `#FCEF9F` (Galben cald / unt, 5 zile)
3. **Fereastră Fertilă (Zilele 11 – 16):** `#B6F5A7` (Verde pastel, 5-6 zile)
4. **Ziua Ovulației (Ziua 14):** `#909CFC` (Albastru-liliac / periwinkle, 1 zi)
5. **Faza Luteală (Zilele 17 – 28):** `#ACEDF3` (Bleu ciel / acvamarin, 12 zile)

---

### 📱 Funcționalități Principale:
- **Ceasul Ciclului Menstrual (Cycle Ring):** Inel progresiv SVG cu segmente multicolore pentru fiecare fază biologică, indicator de zi din ciclu și șanse de concepție.
- **Butonul Principal de Pornire Rapidă:** `+ A început menstruația astăzi` setează instant data curentă ca Ziua 1.
- **Grilă Calendar Lunar Interactivă:** Permite navigarea între luni și selectarea oricărei zile prin click direct pentru a declanșa un nou ciclu. Zilele sunt colorate în nuanțele pastel ale etapelor fiziologice.
- **Pilule Verticale Proporționale:** 5 pilule a căror înălțime vizuală reflectă cu fidelitate durata în zile a fiecărei faze (de la 1 zi pentru Ovulație la 12 zile pentru Faza Luteală).
- **Carduri de Stare ale Fazelor:** 5 carduri biologice detaliate, faza activă primind inel luminos de evidențiere.
- **4 Carduri Informative:** Următoarea Menstruație, Fereastră Fertilă, Ziua Ovulației, Ziua din Ciclu.
- **Recomandare Zilnică:** Sfaturi medicale și de stare de bine adaptate fazei curente.
- **Persistență Locală:** Toate datele sunt salvate în `localStorage`.
- **Resetare Completă:** Buton dedicat pentru a reseta oricând aplicația la starea inițială goală.
